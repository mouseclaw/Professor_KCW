Research Topic 03

Speculative Decoding

Breaking the latency wall with innovations in speculative decoding for large language model inference.

Overview and Motivation

While Large Language Models (LLMs) have achieved remarkable capabilities, their practical deployment is severely constrained by prohibitive inference latency. This bottleneck is an inherent flaw of standard autoregressive text generation. Because standard generation produces only one token per forward pass, the GPU is left severely underutilized, perpetually stalling as it waits for model weights to load into memory. Ultimately, generation speed is bound by memory bandwidth rather than compute power.

Speculative decoding resolves this bottleneck through a "draft and verify" architecture. A highly efficient draft model first generates a sequence of candidate tokens, which the target LLM then verifies in parallel within a single forward pass. By accepting the longest matching prefix, this method directly amortizes memory bandwidth costs over multiple tokens. The result is a substantial acceleration in inference speed without any degradation in output quality, as the final token distribution remains mathematically identical to standard generation.

Our research focuses on maximizing the speedups of speculative decoding in practice by addressing the operational extremes of modern inference. Specifically, we center on two foundational axes: memory-tier optimization and long-context scalability. The first involves developing lightweight drafting mechanisms that operate efficiently within constrained hardware budgets, eliminating the high latency penalties of CPU-GPU weight transfers in offloaded architectures. The second focuses on mitigating the memory-bandwidth bottleneck of massive Key-Value (KV) caches during verification, enabling fast, sparse token evaluation over extensive sequence lengths without compromising acceptance rates.

Research Trajectory:

1. SubSpec: Lossless and Training-Free Acceleration for Offloaded LLMs (NeurIPS 2025)

Deploying massive Large Language Models (LLMs) on memory-constrained hardware often requires parameter offloading—storing a subset of layers in CPU RAM and swapping them to the GPU during inference. While this circumvents VRAM limits, the PCIe bandwidth bottleneck introduces prohibitive latency.

To overcome this, we introduce Substitute Speculative Decoding (SubSpec). SubSpec deploys highly compressed, low-bit quantized "substitute" layers that remain permanently resident on the GPU. This highly aligned draft mechanism rapidly generates a deep token tree, enabling the target model to verify and accept significantly more tokens within a single forward pass, thereby drastically reducing the total number of expensive sequential operations.

Key Contributions

  • Training-Free Substitute Drafting: SubSpec eliminates the need to train or align a standalone draft model. By utilizing heavily quantized versions of the offloaded target layers directly on the GPU, it provides a highly accurate draft mechanism without occupying significant VRAM.
  • Shared Key-Value (KV) Cache Architecture: Unlike traditional speculative decoding setups that maintain isolated KV caches for both the draft and target models, SubSpec allows both models to operate on an identical contextual history. The draft passes extend the KV cache, which the target model then efficiently overwrites or validates during verification, cutting memory footprint in half.
  • Draft Probability Sharpening: To improve acceptance rates, SubSpec introduces a probability sharpening technique. This adjusts the output distribution of the draft model to be more peaked, reducing the probability mass of less likely tokens and guiding the target model toward the most optimal generation paths.
  • Significant Real-World Speedups: Evaluated across diverse benchmarks, SubSpec achieves state-of-the-art acceleration for memory-constrained inference. For example, it demonstrates up to a 9.1x speedup for Qwen2.5 7B (on an 8GB VRAM limit) and an average 12.5x speedup for Qwen2.5 32B (on a 24GB VRAM limit) compared to baseline offloaded inference.

2. Dustin: Draft-Augmented Sparse Verification for Efficient Long-Context Generation with Speculative Decoding (ICML 2026)

As Large Language Models expand their context windows to process tens or hundreds of thousands of tokens, a new inference bottleneck emerges: the Key-Value (KV) cache. In traditional speculative decoding, the verification phase requires fetching the target model's entire KV cache from memory to evaluate the drafted tokens. For ultra-long contexts, the time spent loading this massive cache completely overshadows the computational savings provided by the draft model, severely diminishing the overall speedup.

To resolve this, this work introduces Dustin, a draft-augmented sparse verification framework designed specifically for long-context speculative decoding. Rather than naively loading the entire KV cache during verification, Dustin dynamically identifies and retrieves only the subset of tokens most critical for accurate evaluation. By intelligently minimizing the memory overhead of the KV cache without resorting to aggressive, lossy eviction strategies, Dustin restores the high acceleration potential of speculative decoding even at extreme sequence lengths.

Key Contributions

  • Draft-Augmented Sparse Verification: Dustin introduces a novel verification pipeline that bypasses the need for full KV cache retrieval. It selectively loads only the necessary historical tokens required to verify the draft proposals, drastically reducing memory bandwidth demands during the target model's forward pass.
  • Dual-Signal Attention Fusion: To precisely determine which tokens are critical, Dustin elegantly blends two complementary signals: the lookahead attention from the draft model (indicating what the model expects to focus on next based on its proposals) and the historical attention from the target model (indicating what was recently important).
  • Low-Overhead Dynamic Selection: Standard dynamic KV selection is computationally expensive and can introduce its own latency delays. Dustin leverages the already-computed draft attention states to guide the selection process, minimizing computational overhead and ensuring that the sparse verification remains highly efficient.
  • Robust Long-Context Acceleration: Dustin ensures speculative decoding remains viable at scale by achieving up to a 2.3x speedup on 128k-context Llama-3-8B and a 2.1x speedup on 128k-context Qwen2-7B in multi-batch settings, maintaining negligible deviation from accuracy across downstream benchmarks.
